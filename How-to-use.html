TAU Community Detection

Quick Reference Guide
What is TAU?
A hybrid genetic algorithm for graph clustering that couples global evolutionary search with local Leiden refinements to maximize modularity.
$ pip install tau-community-detection
Basic Usage (Python)
import networkx as nx
import tau_community_detection as tau

# 1. Load Graph (Path is memory efficient)
g = nx.erdos_renyi_graph(100, 0.05, seed=42)

# 2. Run Algorithm
clustering = tau.run_clustering(g)

# 3. Get Results
print(f"Modularity: {clustering.modularity}")
print(f"Communities: {len(clustering)}")
Troubleshooting & Tips
  • Large Graphs: Always pass a file path string to TauClustering instead of a loaded graph object to enable efficient memory sharing across worker processes.
  • Reproducibility: Set seed in TauConfig to ensure consistent runs.
  • Input Formats: Supports .graph, .edgelist, .ncol, and .txt (auto-detects weights).
Key Configuration Parameters

Adjust these using TauConfig to tune performance.

Parameter Default Description
population_size 60 Number of partitions in the pool. Higher = better exploration but slower. Can be overridden in run_clustering().
max_generations 20 Hard limit on iterations. Algorithm may stop early if converged. Can be overridden in run_clustering().
worker_count CPU Count Number of parallel processes. Set to 1 for debugging or notebooks.
p_elite 0.1 Fraction of top partitions kept as-is for the next generation.
stopping_jaccard 0.98 Convergence threshold. Stops if top partitions are 98% similar.
